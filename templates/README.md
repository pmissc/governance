# Templates

This directory contains reusable PMISSC forms, checklists, registers, and document starting points.

Templates should use clear names, indicate their intended purpose, and link to any policy or procedure that requires them.

## Templates

- [License and Access Register](license-and-access-register.md) — blank schema for the restricted operational register.
- [Technology Handover Checklist](technology-handover-checklist.md) — transition and acceptance checklist.
